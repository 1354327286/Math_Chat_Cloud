# Project Modules

Create one directory per registered mathematical problem:

```text
MathDailyLean/Projects/<problem_name>/
```

Keep each module traceable to a plan in
`<problem_dir>/memory/formalization/<slug>.md`. Everything below this directory
except this README is private, ignored by Git, and transported with the matching
problem bundle. Do not register private problem names or mappings in the public
`lean/FORMALIZATION_INDEX.md`.
