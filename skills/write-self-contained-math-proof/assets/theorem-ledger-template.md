# Manuscript Result Ledger

Internal paper-scoped inventory. This selects evidence; it does not certify it
or replace the project's detailed research records. Fill only entries relevant
to this manuscript. Record important inputs, not every routine step or local
definition; reuse valid source and audit evidence. Do not copy this management
text into the article or create this ledger for an isolated routine edit.

- Exact target and agreed assumptions: <statement or full entry below>
- Selected source versions checked on: <date; what was actually checked>

## Result <stable ID>

- Kind: <local result / external input / definition>
- Use in this paper: <included / blocked / excluded; reason>
- Exact statement: <complete statement, quantifiers and conclusion>
- Assumptions and conventions: <include all scope and parameter restrictions>
- Mathematical status: <what is established; any conditionality>
- Evidence: <canonical proof path and section; selected version/date>
- Review evidence: <actual audit path/date/scope and selected revision; identify self-review or independent reviewer; or not yet checked>
- Dependencies: <local IDs and external input IDs; no implicit assumptions>
- Applicability here: <match hypotheses and name the consequence used>
- Unresolved obligations: <precise gap or none known; no invented certification>
- Manuscript location: <stable label/section; distinguish statement from proof>

For an external input, also give authors, title, version/year, stable URL or
identifier, exact theorem/section/page locator and local source path when present.
When a stable canonical statement is directly accessible at that precise
version and locator, reference it rather than copying its full general form.
Still state the exact specialized consequence used here, every applicable
hypothesis and convention, and the applicability bridge. A title-only entry
or a link with no precise used statement is insufficient. Copy the complete
statement when versions are ambiguous or comparison requires it.
Repeat the result block for each important input; selected definitions need provenance
and uses, not a fictitious proof audit.

## Reconciliation notes

Record dated changes to selected statements or dependencies, reasons, affected
uses and rechecks. A source withdrawal blocks dependent entries until resolved.
Retain pointers to superseded evidence; do not overwrite it with a success label.
